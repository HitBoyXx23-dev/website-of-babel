# Contributing

Contributions are welcome.

Keep the project deployable on Vercel, keep public search read-only, and keep personal notes on the user's device unless a feature explicitly requires shared storage.

When adding knowledge or a new data adapter:

- keep source provenance visible
- distinguish established facts from beliefs, folklore, speculation, and generated spaces
- do not invent numeric confidence or prediction percentages
- avoid exposing private personal data or credentials
- prefer public, lawful, documented data sources
- keep the black-and-white interface simple and consistent

Before opening a pull request, run:

```bash
npm run check
```
